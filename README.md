# Подбор партнёрского менеджера — страницы разбора кандидатов

Статический сайт с разбором резюме на вакансию менеджера по развитию партнёрской сети Звонка.
Три этапа подбора, 36 кандидатов. Ноябрь 2026.

## Структура

| Адрес | Что это |
|---|---|
| `/` | Навигация по этапам: сводка, статус по кандидатам, критерии оценки |
| `/step-1` | Первый этап, октябрь 2026, 17 кандидатов (9 от агентства, 8 от внутреннего HR) |
| `/step-2` | Второй этап, ноябрь 2026, 6 кандидатов от агентства |
| `/step-3` | Третий этап, ноябрь 2026, 13 кандидатов от агентства |

`vercel.json` задаёт заголовки: `X-Robots-Tag: noindex` (страницы не попадают в поиск),
`Referrer-Policy: no-referrer`, `X-Content-Type-Options: nosniff`.

Каждая страница — один самодостаточный файл: разметка, стили и данные внутри. Внешних
зависимостей нет, кроме шрифтов Google Fonts (Inter, Caveat). Вверху страниц этапов —
переключатель между ними; ссылки относительные, поэтому работают и на проде, и локально.

## Деплой

Репозиторий подключён к Vercel, каждый push в `main` деплоится автоматически. Без GitHub —
из корня папки: `npx vercel --prod`.

## Как править данные

Оценки и комментарии лежат в массиве `DATA` в конце каждого `index.html` этапа.
У каждого кандидата:

| Поле | Значение |
|---|---|
| `code` | код кандидата: `CV1`, `CV2` и далее. Нумерация своя у каждого этапа, между этапами не пересекается |
| `pay` | ожидания по зарплате |
| `score` | итоговая оценка от 1 до 10 |
| `tier` | приоритет `A`, `B` или `C` — им же задаётся порядок строк |
| `bars` | оценки 1–5 по критериям, в порядке массива `LABELS` над функцией рендера |
| `verdict`, `plus`, `minus` | текст в раскрывающейся карточке |
| `CVLINK` | отдельный объект: код кандидата → ID файла резюме в Google Drive |

Порядок строк считается автоматически: сначала приоритет, внутри него — оценка по убыванию.
Счётчики A / B / C в шапке пересчитываются сами.

На первом этапе у кандидатов есть ещё поля `src` (`ag` — агентство, `hr` — внутренний HR)
и `city`, и по ним работают дополнительные фильтры.

Сводные цифры на главной (`index.html`) записаны руками — при добавлении этапа их нужно
обновить там же: блок `.stats` и карточки `.stage`.

## Как добавить следующий этап

1. Скопировать папку `step-3` в `step-4`, заменить данные в `DATA` и `CVLINK`.
2. Дописать ссылку в блок `.sitenav` вверху всех страниц этапов.
3. Добавить карточку `.stage` на главной и поправить сводные цифры.
