# Скоринг кандидатов — менеджер по развитию партнёрской сети

Статическая страница с оценкой 17 кандидатов на вакансию партнёрского менеджера Звонка
(9 от HR-агентства, 8 от внутреннего HR). Октябрь 2026.

## Что внутри

- `index.html` — вся страница одним файлом: разметка, стили и данные по кандидатам в массиве `DATA` внизу файла. Внешних зависимостей нет, кроме шрифтов Google Fonts (Inter, Caveat).
- `vercel.json` — заголовки: `X-Robots-Tag: noindex` (страница не попадает в поиск), `Referrer-Policy: no-referrer`, `X-Content-Type-Options: nosniff`.

## Деплой

Репозиторий уже инициализирован и содержит первый коммит. Нужно создать пустой репозиторий на GitHub и запушить:

```bash
git remote add origin git@github.com:<аккаунт>/<репозиторий>.git
git branch -M main
git push -u origin main
```

Дальше на vercel.com: **Add New → Project → Import Git Repository**, выбрать этот репозиторий.
Framework Preset — **Other**, build command и output directory оставить пустыми: это статика,
собирать нечего. После импорта каждый push в `main` деплоится автоматически.

Альтернатива без GitHub — из этой папки:

```bash
npx vercel --prod
```

## Как править данные

Оценки и комментарии лежат в массиве `DATA` в конце `index.html`. У каждого кандидата:

| Поле | Значение |
|---|---|
| `code` | код кандидата: `CV1`–`CV9` (агентство), `HR1`–`HR8` (наш HR) |
| `src` | `ag` — агентство, `hr` — наш HR; определяет бейдж в таблице |
| `city` | `МСК`, `КЗН` или `—` |
| `pay` | ожидания по зарплате; `over: true` подсвечивает их красным при выходе за вилку |
| `score` | итоговая оценка от 1 до 10 |
| `tier` | приоритет `A`, `B` или `C` — им же задаётся порядок строк |
| `bars` | шесть оценок 1–5 в порядке: хантинг, сегменты, IT/SaaS, продажи, активация, масштаб |
| `verdict`, `plus`, `minus` | текст в раскрывающейся карточке |

Порядок строк считается автоматически: сначала приоритет, внутри него — оценка по убыванию.
Счётчики A / B / C в шапке тоже пересчитываются сами, руками их править не нужно.

Ссылки на резюме — в объекте `CVLINK`: это ID файлов в Google Drive. Папка закрыта правами
Drive, поэтому у человека без доступа к ней кнопки `PDF` не откроются, даже если сама страница
открыта. Это задумано: на странице — только оценки, персональные данные остаются в Drive.
